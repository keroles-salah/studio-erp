1 قاعدة البيانات — Supabase (مجاني)

  1. supabase.com → New project باسم studio-erp — Region: Frankfurt.
  2. احفظ Database Password فوراً (مش هيظهر تاني).
  3. Settings → Database → Connection string (URI). الاستضافة بتبقى بالشكل ده:
postgresql://postgres:[PASSWORD]@db.<PROJECT-REF>.supabase.co:5432/postgres
⚠️ مهم: استخدم port مباشر 5432. لو المشروع جديد وport 5432 المقفول، استخدم Session mode pooler بنفس الـ port 5432 — وتجنّب Transaction pooler (6543) مع Prisma migrations.

2 إنشاء الجداول في Supabase

من مجلد backend على جهازك:

$env:DATABASE_URL = "postgresql://postgres:<PASSWORD>@db.<PROJECT-REF>.supabase.co:5432/postgres"
npx prisma db push --schema prisma/schema.postgresql.prisma
npx prisma generate --schema prisma/schema.postgresql.prisma
✓ ملحوظة: المشروع فيه أصلاً ملف schema.postgresql.prisma جاهز للإنتاج — الـ Dockerfile بيعتمد عليه.

5 تحديث Vercel

  1. Settings → Environment Variables:
VITE_API_URL = https://<backend-url>/api/v1
  1. Deployments → Redeploy.
🔴 HTTPS إجباري: فرونت على https://vercel.app مينفعش ينادي backend على http:// — المتصفح بيمنع Mixed Content. رابط Render بيجي HTTPS جاهز فالحل سليم.

6 التحقق النهائي
